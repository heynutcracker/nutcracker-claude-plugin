# Nutcracker for Claude

[Nutcracker](https://heynutcracker.com) is a creative copilot for marketing and brand teams. This plugin connects Claude to it, so you can brief Nutcracker from a Claude chat: strategy, ideas, copy, naming, research with every source linked, presentations and storyboards, all filed in your brand's space.

## What you get

- Start a task in a space and follow it until it is done.
- Read, edit, share and export the docs, presentations and storyboards it makes.
- Upload files and brand material the space keeps for every chat.

This connection makes no pictures, clips or sound. A task writes each one as a card with its price, and you run the ones you want in the Nutcracker app.

## Install

In Claude Code:

```
/plugin marketplace add heynutcracker/nutcracker-claude-plugin
/plugin install nutcracker@nutcracker
```

Then type `/mcp`, pick nutcracker and sign in to Nutcracker. You need a Nutcracker account.

Setup for other apps: https://heynutcracker.com/connect
